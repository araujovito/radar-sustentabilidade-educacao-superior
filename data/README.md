# Dados locais

Os dados desta pasta não são versionados.

- `raw/`: arquivos obtidos sem alteração da fonte oficial;
- `interim/`: arquivos temporários e padronizações intermediárias;
- `processed/`: tabelas e artefatos prontos para análise.

Cada arquivo de origem deverá ter URL, data de obtenção, tamanho e checksum
registrados no banco.
